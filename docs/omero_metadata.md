# OMERO Metadata Support

The OME-Zarr Writer now supports OMERO metadata for channel display configuration. This feature allows you to define how channels should be displayed in compatible viewers like napari.

## Usage

To add OMERO metadata to your OME-Zarr images, create `Omero` objects with channel configuration and pass them to the `OmeZarrImage` constructor:

```python
from ome_zarr_writer.image import OmeZarrImage
from ome_zarr_writer.schema_models import Omero, Channel, Window

# Create channel display configuration
channels = []

# Red channel
red_window = Window(start=1000.0, min=0.0, end=50000.0, max=65535.0)
red_channel = Channel(
    window=red_window,
    label="Red Fluorescence",
    color="FF0000",  # Hex color without #
    active=True,
    family="linear"
)
channels.append(red_channel)

# Green channel
green_window = Window(start=500.0, min=0.0, end=40000.0, max=65535.0)
green_channel = Channel(
    window=green_window,
    label="Green Fluorescence",
    color="00FF00",
    active=True
)
channels.append(green_channel)

# Create OMERO metadata
omero_metadata = Omero(channels=channels)

# Create OME-Zarr with OMERO metadata
ome_zarr = OmeZarrImage(
    path="image_with_omero.ome.zarr",
    image=your_image_data,
    dims=["c", "y", "x"],
    axis_units={"c": None, "y": "micrometer", "x": "micrometer"},
    omero_metadata=omero_metadata,  # Add OMERO metadata
    overwrite=True
)

ome_zarr.write()
```

## OMERO Data Structure

### Channel
The `Channel` class defines display properties for each channel:

- `window`: (required) `Window` object defining display range
- `label`: (optional) Channel name for display
- `color`: (optional) Hex color string (without #)
- `active`: (optional) Whether channel is initially visible
- `family`: (optional) Rendering family (e.g., "linear")

### Window
The `Window` class defines the display range for a channel:

- `start`: Start of display range
- `min`: Minimum data value
- `end`: End of display range  
- `max`: Maximum data value

### Omero
The `Omero` class contains the channel configuration:

- `channels`: List of `Channel` objects

## Schema Compliance

The OMERO metadata generated by this library conforms to the OME-Zarr 0.5 specification as defined in `src/spec/0.5/schemas/image.schema`. The metadata is optional - if not provided, OME-Zarr files are created without OMERO metadata.

## Examples

See `examples/omero_metadata_example.py` for a complete working example that creates a multichannel image with OMERO metadata.

## Validation

OMERO metadata is automatically validated when creating `Channel`, `Window`, and `Omero` objects. The validation ensures:

- Required fields are present
- Data types are correct
- Values are within expected ranges

## Compatibility

OME-Zarr files with OMERO metadata can be opened in:

- napari (with zarr plugin)
- ImageJ/Fiji (with Bio-Formats)
- Other OME-Zarr compatible viewers

The OMERO metadata provides display hints to these viewers for optimal channel visualization.
